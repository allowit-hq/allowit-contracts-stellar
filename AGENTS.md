# Repository scope

Keep contract implementation, the `crates/allowit-stellar` off-chain rail crate (`allowit-stellar`) that the SDK engine composes, technical build/API documentation and release inputs in this repository. Do not commit plans, research, reviews, acceptance reports, recordings or generated evidence here.

Before any change, check out [allowit-hq/allowit-project](https://github.com/allowit-hq/allowit-project), read its task register (`wiki/tasks/README.md`) and the plan that owns the work, log the task there first, and name it (`TASK-<number>`) in the title of the pull request or on a `Task:` line of its description.

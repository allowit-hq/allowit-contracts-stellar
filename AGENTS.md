# Repository scope

Keep contract implementation, the `stellar/core` off-chain rail crate (`allowit-stellar-wallet`) that the SDK engine composes, technical build/API documentation and release inputs in this repository. Planning, research, reviews, acceptance reports, recordings and generated evidence belong to the canonical `allowit-hq/allowit-project` knowledge repository: original supplied inputs under `.agents/1-sources/`, human knowledge in `wiki/`, and generated task outputs in `.agents/artifacts/`. Preserve original source bodies and file hashes before removing historical outputs here. Do not commit task artifacts or reports in this repository. Use explicit output paths in the main project for retained generated evidence.
